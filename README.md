# AHU Demo — 3D-планировщик и AR

Демо-инструмент для производителя приточных установок (AHU) для дата-центров США.

- **index.html** — 3D-планировщик: вводишь IT-нагрузку дата-центра, он считает количество установок с резервом и показывает их на площадке.
- **ar.html** — одна установка в дополненной реальности на телефоне, в натуральную величину.

## Структура

```
ahu-demo/
├── server.js            сервер для Railway (Express)
├── package.json
└── public/
    ├── config.js        ← ВСЕ НАСТРОЙКИ ЗДЕСЬ
    ├── index.html       3D-планировщик
    ├── ar.html          AR-страница
    └── js/
        └── unit-model.js  3D-модель установки (общая для обеих страниц)
```

## Как менять настройки

Всё в одном файле: `public/config.js`. Внутри есть комментарии к каждому полю.

- **unit** — размеры, расход воздуха, вес, зона обслуживания, длина транспортной секции.
- **sources** — пометка для каждой цифры: `spec` (данные производителя), `ref` (из открытого источника), `assumed` (заглушка). Пометки видны в интерфейсе рядом со значениями.
- **defaults** — с какими значениями открывается планировщик (МВт, ΔT, резервирование, размещение).
- **colors** — цвета модели.

3D-модель для AR строится прямо в браузере из `config.js`, поэтому после изменения ничего пересобирать не нужно: сохранили файл, обновили страницу.

Поля в блоке «Unit data» на самой странице тоже можно менять, но только до перезагрузки. Постоянные изменения делаются в `config.js`.

## Запуск на своём компьютере

```bash
cd ahu-demo
npm install
npm start
```

Откройте http://localhost:3000 (планировщик) и http://localhost:3000/ar.html (AR).
AR с компьютера не запустится, для него нужен телефон и HTTPS, то есть Railway.

## Выкладка на Railway

```bash
cd ahu-demo
git init
git add .
git commit -m "AHU demo"
git remote add origin https://github.com/ВАШ_ЛОГИН/ahu-demo.git
git branch -M main
git push -u origin main
```

Дальше в Railway: **New Project → Deploy from GitHub repo → ahu-demo**,
затем **Settings → Networking → Generate Domain**.

После каждого изменения:

```bash
git add .
git commit -m "Описание изменения"
git push
```

Railway пересоберёт проект сам.

## Что пока на заглушках

Смотрите `sources` в `config.js`: всё, что помечено `ref` или `assumed`, нужно заменить реальными данными производителя.
